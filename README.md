# PlanCheckBox-python

丢入任务文件，就能看到对应的月度、周度、每日的安排；也可以**直接在界面上创建自己的计划**——点按钮、填表单、勾选完成，不需要手写任何文件。

零第三方依赖，Python 3.8+ 一条命令启动。

## 快速开始

```bash
python3 app.py
```

浏览器会自动打开 `http://127.0.0.1:8765`。首次启动会生成 3 个示例计划，方便直接体验。

```bash
python3 app.py --port 9000 --no-browser   # 自定义端口 / 不自动打开浏览器
```

## 功能一览

### 在界面上创建计划（无需导入文件）

点右上角 **「新建计划」**（快捷键 `N`）：

- **基本信息**：名称、12 个图标、8 种颜色、起止日期（7 / 30 / 90 天快捷选择）、备注
- **三种任务录入方式**，可混合使用：
  - **逐条添加**：一行一个任务，回车自动加行
  - **批量粘贴**：每行一个任务，支持 `2026-11-20 任务标题` 指定日期
  - **每周重复**：填一个标题 + 勾选星期，在日期范围内自动生成（如「每周一三五背单词」）
- 右侧**实时预览**任务清单与覆盖天数，创建前一目了然

### 三种视图

| 视图 | 内容 |
| --- | --- |
| 月 | 日历热力点阵，一眼看出每天的安排密度与完成情况 |
| 周 | 7 列任务卡片，适合安排一周节奏 |
| 日 | 当日任务按分组展示，含进度条、连续达成天数、逾期任务「顺延到今天」 |

### 日常操作

- 点 checkbox 完成任务，进度实时更新并持久化
- 每天 / 每周列 / 每月格子都有 **「＋」快速添加**任务
- 点任务标题可编辑（标题、日期、备注、移动到别的计划）
- 删除任务 / 计划后 6 秒内可 **撤销**
- 左侧计划列表：进度环、拖拽排序、按名称 / 进度 / 任务数排序、点击查看详情抽屉
- 顶部搜索：跨计划搜索任务与计划名，结果高亮
- 「只看此计划」筛选；视图与排序偏好自动记住

### 导入 / 导出

- 顶部「导入」按钮或**直接把 JSON 文件拖进页面**，导入前有预览确认
- 兼容三种格式：
  1. 本应用原生格式（`samples/原生格式示例_英语词汇.json`）
  2. 原版 PlanCheckBox 的 `*_checkbox_use.json`（`samples/原版格式示例_健身.json`）
  3. 简易任务数组 `[{"title": "...", "date": "2026-11-20", "done": false}]`
- 单个计划或全部计划可导出为 JSON，随时备份迁移

### AI 助手（LLM 聊天）

顶栏「AI 助手」打开右侧聊天面板（移动端全屏）。实现方法参考 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo)：

- **浏览器直连 API**：默认 `https://api.deepseek.com`，走 Anthropic 兼容的 Messages 接口（`/anthropic/v1/messages`，SSE 流式）；API 地址、模型（deepseek-flash / deepseek-v4-pro）可在设置中修改
- **Key 只存本浏览器**：保存在 localStorage，不经过本应用服务器；设置里可一键验证（GET /models，不产生费用）
- **计划感知**：助手自动了解你的全部计划、进度与今日任务，可以回答「我今天该做什么」「复盘这周进度」
- **AI 提案一键建计划**：让 AI 制定计划时，回复中会出现计划提案卡片，点「创建此计划」直接入库
- **完整聊天体验**：流式回复 + 停止生成、重新生成、错误重试、深度思考（可开关，思考过程可折叠查看）、Markdown / 代码块 / 表格渲染与复制
- **多会话**：新建 / 切换 / 重命名 / 删除（可撤销），自动标题；会话历史保存在本机 `data/chat/` 目录，刷新与重启不丢

> 隐私说明：发送对话时，消息内容会直接提交给你配置的 API 服务；本应用服务器只保存会话历史，不接触 API Key。

### 快捷键

| 键 | 作用 |
| --- | --- |
| `N` | 新建计划 |
| `T` | 回到今天 |
| `1` / `2` / `3` | 月 / 周 / 日视图 |
| `←` / `→` | 切换时间段 |
| `/` | 聚焦搜索 |
| `Esc` | 关闭弹窗 / 抽屉 |

## 数据存储

- 所有数据保存在 `data/` 目录，**一个计划一个 JSON 文件**，写入为原子操作
- 数据完全在本机，不上传任何内容；备份只需复制 `data/` 目录
- 删除 `data/` 后重启会重新生成示例计划

## 项目结构

```
app.py                  # 本地服务 + REST API（Python 标准库）
static/
  index.html            # 页面结构
  app.css               # 视觉系统（纸感配色 / 动效 / 响应式）
  app.js                # 计划交互逻辑（原生 JS，零依赖）
  chat.css              # AI 助手面板样式
  chat.js               # AI 助手：SSE 流式客户端 / Markdown / 会话管理
samples/                # 两种格式的导入示例
tests/test_ui.py        # 计划功能端到端测试（Playwright + 系统 Chrome）
tests/test_chat.py      # AI 助手端到端测试
tests/mock_llm.py       # 模拟 DeepSeek 兼容 API（测试用）
data/                   # 运行时生成（已 gitignore）：计划 + data/chat/ 会话
```

## API 简表

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 全部计划 + 今天日期 + 配色/图标 |
| POST | `/api/plans` | 创建计划（也用于撤销删除时恢复） |
| PUT / DELETE | `/api/plans/<id>` | 更新 / 删除计划 |
| POST | `/api/plans/<id>/tasks` | 添加任务 |
| PUT / DELETE | `/api/plans/<id>/tasks/<tid>` | 更新 / 删除任务 |
| POST | `/api/import` | 导入，`{"payload": ..., "dryRun": true}` 可预览 |
| POST | `/api/reorder` | 计划排序 |
| GET | `/api/export[/<id>]` | 导出全部 / 单个计划 |
| GET | `/api/chat/sessions` | 聊天会话列表 |
| PUT / DELETE | `/api/chat/sessions/<id>` | 保存 / 删除会话 |
